# ⚔️ 아발론 온라인

친구들과 함께하는 웹 아발론 (The Resistance: Avalon). **최소 5명 · 최대 10명**.
서버가 필요 없어 GitHub Pages에 올리기만 하면 바로 쓸 수 있습니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다. 예: `avalon` (Public)
2. 이 폴더의 파일(`index.html`, `app.js`, `game.js`, `style.css`, `.nojekyll`, `README.md`)을 저장소 루트에 올립니다.
   - 웹에서 올릴 때: 저장소 → **Add file → Upload files** → 파일 끌어다 놓기 → Commit
   - 터미널에서 올릴 때:
     ```bash
     git init && git add . && git commit -m "아발론 온라인"
     git branch -M main
     git remote add origin https://github.com/<내아이디>/avalon.git
     git push -u origin main
     ```
3. 저장소 **Settings → Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 Save
4. 1~2분 뒤 `https://<내아이디>.github.io/avalon/` 에서 플레이할 수 있습니다.

## 플레이 방법

- **호스트**: 닉네임 입력 → **방 만들기** → 5자리 방 코드나 **초대 링크**를 친구들에게 공유
- **플레이어**: 초대 링크를 열거나 방 코드를 입력하고 **입장하기**
- 대기실에 현재 인원(`n / 10명`)과 최소 인원(5명) 표시가 나오고, 5명 미만이면 시작 버튼이 잠깁니다.
- 호스트가 역할(퍼시발·모르가나·모드레드·오베론, 호수의 여인)을 고르고 **게임 시작**

| 인원 | 선 | 악 | 퀘스트별 원정대 인원 |
|---|---|---|---|
| 5 | 3 | 2 | 2 · 3 · 2 · 3 · 3 |
| 6 | 4 | 2 | 2 · 3 · 4 · 3 · 4 |
| 7 | 4 | 3 | 2 · 3 · 3 · 4* · 4 |
| 8 | 5 | 3 | 3 · 4 · 4 · 5* · 5 |
| 9 | 6 | 3 | 3 · 4 · 4 · 5* · 5 |
| 10 | 6 | 4 | 3 · 4 · 4 · 5* · 5 |

\* 4번째 퀘스트는 실패 카드가 2장 이상이어야 실패합니다.

## 구현된 규칙
- 비밀 역할 배정과 역할별 정보 (멀린, 퍼시발, 악의 세력끼리 확인, 모드레드·오베론 예외)
- 대표 순환, 원정대 제안, 공개 찬반 투표 (과반 찬성 시 가결, 5연속 부결 시 악 승리)
- 비밀 퀘스트 카드 (선은 실패 카드를 낼 수 없음)
- 3승/3패 판정, 암살자의 멀린 암살
- 호수의 여인 확장 (7명 이상)
- 투표 및 퀘스트 기록, 게임 종료 후 전체 역할 공개, 같은 멤버로 다시 하기

## 편의 기능
- **진행 안내**: 화면 위쪽에 지금 누가 무엇을 하는 중인지 표시 (원정대를 꾸리는 중, 찬반 투표 중, 성공/실패를 고르는 중, 멀린을 최종 지목하는 중 등). 내 차례면 강조되고 진동이 울립니다.
- **5분 제한 시간**: 대표가 원정대를 꾸리는 시간은 5분이며 모든 사람에게 남은 시간이 보입니다. 시간이 지나면 원정대가 무작위로 선택됩니다.
- **Last 5분**: 대표는 자기 턴마다 한 번, 남은 시간에 5분을 더할 수 있습니다.
- **역할 카드**: "내 역할 확인하기"를 누르면 역할 일러스트 카드와 함께, 플레이어 목록에 같은 편(또는 알고 있는 정보)이 표시됩니다. 잠그면 표시가 사라집니다.
- **채팅**: 오른쪽 아래 💬 버튼. 대화와 게임 진행 기록이 방이 열려 있는 동안 남고, 늦게 들어온 사람도 이전 대화를 볼 수 있습니다.
- **이펙트**: 퀘스트 결과 카드가 한 장씩 뒤집히며 성공/실패 연출이 나오고, 게임이 끝나면 승리 연출이 나옵니다.

## 동작 방식과 주의사항
- **호스트의 브라우저가 게임 서버**입니다. 메시지는 공개 MQTT 중계 서버 5곳(보안 WebSocket)을 동시에 거쳐 오갑니다. 공통으로 닿는 서버가 하나만 있어도 연결되므로 와이파이·모바일 데이터 어디서나 접속할 수 있습니다.
- 첫 화면의 **열려 있는 방** 목록에서 바로 입장하거나, 방 코드·초대 링크로 들어올 수 있습니다.
- 호스트가 창을 닫으면 게임이 멈춥니다. 같은 브라우저에서 다시 열고 **"내가 만든 방 다시 열기"**를 누르면 진행 중이던 게임이 복구되고, 플레이어들은 자동으로 재연결됩니다.
- 플레이어 연결이 끊기면 자동으로 다시 연결합니다. 새 탭으로 다시 들어올 때는 **같은 닉네임**으로 입장하면 원래 자리로 돌아갑니다.
- 공개 중계 서버를 쓰기 때문에 마음먹은 사람이 통신 내용을 엿볼 수는 있습니다. 친구들끼리 즐기는 용도로 사용하세요.
- 음성 채팅이나 같은 자리에서 대화하며 플레이하는 것을 전제로 합니다. 채팅 기능은 없습니다.
